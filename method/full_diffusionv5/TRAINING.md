# V5：4Hz 连续训练，每个锚点刷新世界模型

参考代码：neasonrum/WMMPC，commit `0c8a65142739515d2c9796d7358dd35b67d150da`。
本目录实现训练部分；闭环调度尚未确定，也未部署 V5 CARLA agent。

## 时间定义

- 每条路线是一条 4Hz 顺序链，锚点逐帧推进 0.25s，不拆奇偶帧。
- 每个锚点只有一个当前时刻，输入三帧观测 `t-0.5, t-0.25, t`。
- 先验来自同一路线 `t-0.25` 时刻模型自己生成的时间分支，25 步 DDIM，无梯度。
- 用真实已观测自车位姿做 SE(2) 对齐，对旧轨迹按时间插值前移 0.25s。
- 旧轨迹覆盖不到当前 `t+3s`，第六段先验设为无效；不进行尾部外推。
- 每个锚点以自己的历史和已对齐先验生成新的未来 BEV；缓存年龄恒为 0。
- 采样当前 `t+[0.5,1,1.5,2,2.5]s` 的五张未来图，保持 95 个邻域 token。
- 保留时间和空间两个分支。沿用参考 V5 的冻结 V3 头、标签和归一化
  （10 个几何空间点、6 个时间点），本次只调整训练时间逻辑。
- BCDE 世界模型冻结；训练未来采样器和两分支的零门控适配模块。
- 路线切换、时间回退或帧缺口均冷启动，用冻结 V3 生成第一条滚动先验。
- 未来真实轨迹、速度与位姿仅用于标签；不进入世界模型或邻域条件。

例如在 `t=1.25s`：观测 `[0.75,1.00,1.25]s`，先验源 `P_1.00`，
生成/采样 BEV 的绝对时间为 `[1.75,2.25,2.75,3.25,3.75]s`。
下一项 `t=1.50s` 使用 `P_1.25` 并重新滚动，不复用上一项的世界缓存。

## 数据与缓存

保留原 seed901 数据索引的有效训练/验证路线划分。重新枚举每条路线内所有
历史连续且有完整 3s 未来的 4Hz 锚点，包括原三锚点 item 会丢弃的末尾两项。
这不表示训练使用了 PDMlite 目录中所有可能的路线。

新索引路径：`data/full_diffusionv5/pdm_seed901_train4hz_fresh_v1`。
旧教师 BEV 缓存直接复用；`prepare features` 校验所需 NPY 头并仅补缺帧。
缺缓存不会使对应训练样本被静默删掉。
`prepare contexts` 按帧号复用同教师的 V4 memory/ego，只重新提取未覆盖的帧。
新缓存完成标记绑定新索引 identity，训练在缓存未齐时拒绝启动。

## 运行

在已有计算分配内：

```bash
bash tools/train_v5_train4hz_tongji.sh method/full_diffusionv5/config_train4hz.json all
```

可以分阶段运行，将末尾 `all` 改为 `labels`、`features`、`contexts` 或 `train`。
默认训练配置为 8 GPU × 每卡 32 项、5 个样本预算 epoch。训练流跨 epoch 继续，
每个 epoch 的含义为 `ceil(train_items/global_batch)` 次更新，不保证每条路线恰好一遍。
数据准备可使用不同数量的 GPU；训练进程数必须等于配置 `training.world_size`。
批量与卡数应在得到计算资源后通过独立配置确定，并写入训练输出。
续训设置 `RESUME=1`；短跑检查可设置 `MAX_UPDATES=3`。
脚本沿用现有计算分配，不申请、取消或释放 GPU，也不启动 CARLA。

## 验证与结果

验证也用单条 4Hz 链、0.25s 先验、新鲜世界和 25 步去噪。
V5 与冻结 V3 每项共享相同初始噪声。记录按路线平均的空间 ADE、未来位置 ADE，
分别汇报全部帧与世界条件可用帧，最佳权重按后者的未来 ADE 选择。
训练日志记录先验年龄、缓存年龄、有效先验点数和世界条件可用率。

新权重格式 `full_diffusionv5_train4hz_v1` 与索引格式
`full_diffusionv5_index_train4hz_v1` 单独标记。仅支持同配置、同索引的精确续训。
参考 V5 的旧 2Hz 闭环加载器会拒绝此格式；闭环频率确定后再适配并验证。
本次修改本身不启动全量数据准备或训练。
